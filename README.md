### Prequisites

* dotnet-runtime-9.0

### Building

1. Install dotnet-sdk-9.0 on your system.
2. Clone the repository
   ```sh
   git clone https://github.com/scruffiebaka/Ion.git
   cd Ion
   ```
3. Build
   ```sh
   dotnet build
   ```
4. Build will be located in Ion/bin/Debug/net9.0
   ```sh
   cd Ion/bin/Debug/net9.0
   ```
